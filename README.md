# Request Help

Request Help is a Moodle activity for situations where students need to ask for help during a lesson without interrupting the flow of the class or losing track of who asked first. Each activity works as a help queue: students choose a configured subject, describe the question or problem, and submit it to the teacher.

Teachers see the requests in a central queue ordered by status and creation time. A request can be claimed by a teacher, answered directly in Moodle, marked as answered in class, resolved, or reopened when more information is needed.

## How it works

A teacher adds the activity to the course and defines the subjects that students can choose from. When a student needs help, they open the activity, select a subject and describe the problem. The request enters the queue as Open.

The teacher can take ownership of a request and either write a response or use the Answered in class action when the interaction happened face to face. Written replies stay in the conversation history. The activity records the time until the first response, which makes it possible to see how long students are waiting for support.

Depending on the activity settings, students can mark their own requests as resolved and reopen a resolved request. When a student adds new information to an answered request, it returns to the Open queue so it is not silently lost.

## Main features

- Central help queue for each activity.
- Configurable subjects, one per line.
- Open, Answered and Resolved statuses.
- Automatic teacher queue refresh.
- Written conversation history.
- Answered in class action without requiring a typed response.
- Teacher assignment and request claiming.
- First-response time tracking.
- Filters by status and subject.
- Student view containing only their own requests.
- Optional student resolve and reopen actions.
- Moodle events for activity views, request creation, answers and resolution.
- Privacy API support for discovery, export and deletion of user data.
- Backup and restore support, including event log mappings.
- Responsive interface.
